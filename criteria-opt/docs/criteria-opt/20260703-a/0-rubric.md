## [최종 Rubric]
- 스킬 목적 상세 분석: `criteria-opt`의 첫 책임은 대상 스킬을 바로 고치거나 자동 루프를 돌리는 것이 아니라, 대상 스킬의 최종 목적을 기준으로 개선 판단에 사용할 평가 기준을 먼저 1회 고정하는 것이다. 이 평가지는 이후 개선 제안, 패치 수락, 중단 판단이 사후 합리화나 인상비평으로 흐르지 않도록 목적 정합성, 객관성, 측정 가능성, 근거 추적성, 최소 개선 원칙을 검증한다. 평가 기준은 개선보다 먼저 존재해야 하며, 이후 루프는 기준 밖의 변경을 성과로 인정하지 않아야 한다.

### 평가 항목 정의
| 평가 항목명 | 고득점 요건 (100점 기준) | 기반 근거 (Rationale) |
| :--- | :--- | :--- |
| 평가 기준 선행 고정성 | 대상 스킬 개선, 루프 설계, 패치 제안보다 먼저 평가 기준표를 단 1회 생성하고, 동일 개선 세션 안에서 항목 추가, 삭제, 의미 변경을 하지 않는다. 명백한 오탈자나 구조 오류 수정만 별도 기록과 함께 허용한다. | 기준이 개선 이후 또는 루프 중간에 바뀌면 결과에 맞춰 잣대를 조정할 수 있어 객관성이 무너진다. `criteria-opt`는 개선 전에 판단 기준을 고정해야 이후 결정을 통제할 수 있다. |
| 목적 정합성 | 모든 평가 항목과 100점 요건이 대상 스킬의 최종 목적, 요구사항, 실패 방지 조건과 직접 연결되어야 한다. 루프 구현 편의, 일반적 품질론, 선호 스타일처럼 목적 달성과 직접 연결되지 않는 항목은 포함하지 않는다. | 평가 기준은 대상 스킬이 본래 해야 할 일을 달성했는지 판정하기 위한 것이다. 목적과 무관한 기준은 개선 루프를 잘못된 방향으로 최적화한다. |
| 객관성 및 재현 가능성 | 각 기준은 관찰 가능한 산출물, 명시적 조건, 절차 준수 여부, 제약 위반 여부로 판정 가능해야 하며, 서로 다른 평가자가 같은 입력을 보아도 유사한 결론에 도달할 수 있어야 한다. | `criteria-opt`는 인상비평을 피해야 한다. 평가자의 취향이나 해석에 따라 결과가 크게 달라지면 기준표는 개선 통제 장치로 기능하지 못한다. |
| 정량적 측정 가능성 | 각 차원은 100점 만점 조건과 감점 사유를 구체적으로 제시하고, 필수 요소 수, 누락 여부, 증거 매핑 비율, 단계 준수 여부, 금지 조건 위반 여부처럼 점수화 가능한 판정 단위를 포함한다. | 개선 전후 비교와 패치 수락 판단은 측정 가능한 기준이 있어야 가능하다. 측정 불가능한 기준은 설득력 있는 설명을 점수처럼 오인하게 만든다. |
| 근거 추적성 | 각 평가 항목은 입력된 스킬 목적 또는 요구사항 중 어느 부분에서 도출되었는지 근거를 설명하고, 이후 평가자가 기준 적용 결과를 산출물이나 기록으로 재검토할 수 있어야 한다. | 평가 기준이 임의로 보이면 이후 루프가 기준을 오해하거나 확장하기 쉽다. 근거 추적성은 기준의 정당성과 수정 금지 범위를 확인하게 해준다. |
| 개선 루프 통제력 | 이후 개선 제안, 패치, 수락, 보류, 중단 판단이 고정 기준표의 항목에 매핑되어야 하며, 기준 밖의 개선안이나 목적 외 최적화는 보류 또는 거부하도록 절차가 명확해야 한다. | 평가지는 문서로 끝나지 않고 루프의 실제 의사결정을 제한해야 한다. 이 연결이 없으면 `criteria-opt`는 평가 기준을 만들고도 패치 제안 자체를 성과로 착각할 수 있다. |
| 최소 개선 원칙 | 기준표는 목적 달성에 필요한 가장 작은 변경을 선호해야 하며, 불필요한 구조 변경, 범위 확장, 추상화 추가, 문서 과잉 생산, 기능 추가를 고득점 요건으로 삼지 않는다. | `criteria-opt`는 대상 스킬을 과잉 설계하지 않도록 보호해야 한다. 최소 개선 원칙이 없으면 평가 기준 자체가 더 큰 변경을 보상한다. |
| 과도한 자동화 억제 | 자동 승인, 자동 패치, 자동 반복, 자동 기준 수정이 허용되는 조건과 금지되는 조건을 구분하고, 불확실성, 근거 부족, 충돌, 안전 문제에서는 자동 진행보다 보류 또는 인간 확인을 우선하도록 평가한다. | 요구사항은 과도한 자동화를 피하는 것이다. 자동화가 무제한 허용되면 목적 검증보다 실행 속도와 변경량이 우선되어 품질과 책임성이 떨어진다. |
