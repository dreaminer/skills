Characterization Test

수정 전 코드의 실제 관찰 결과를 테스트로 고정한다.

묻는 질문현재 시스템은 무엇을 하는가?
기대값의 출처실행하여 관찰한 현재 결과
목적의도하지 않은 행동 변화 감지
보장하지 않는 것현재 행동이 업무적으로 옳다는 것
좋은 경계응답, 저장 변화, 발행 이벤트처럼 외부에서 관찰 가능한 결과

작성 순서

  1. 변경할 흐름과 관찰 가능한 경계를 고른다.
  2. 대표 입력으로 현재 코드를 실행한다.
  3. 관찰된 결과를 기대값으로 기록한다.
  4. 테스트가 반복해서 같은 결과로 통과하는지 확인한다.
  5. 그 뒤 구현을 변경한다.
