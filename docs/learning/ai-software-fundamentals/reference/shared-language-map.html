공통 언어: 작은 계약 지도

용어집의 목적은 말을 예쁘게 맞추는 일이 아니라, 에이전트의 선택지를 안전하게 줄이는 것이다.

용어이 프로젝트에서의 뜻반드시 함께 적을 것
후보아직 최종으로 확정되지 않은 항목후보가 된 조건과 최종 상태로 가는 경로
오래됨마지막 활동 시각이 정한 기준보다 앞선 상태기준 시각·시간대·누락 시각의 처리
정리후보를 더 이상 기본 목록에 보이지 않게 하는 행위삭제·보관·숨김 중 실제 동작과 복구 가능성

추가할지 판단하는 세 질문

  1. 이 단어를 두 사람이 다른 상태·행동·경계로 구현할 수 있는가?
  2. 이 정의를 바꾸면 테스트의 기대값도 바뀌는가?
  3. 요청·코드·테스트 중 둘 이상에서 반복되는가?

하나라도 “예”라면 한두 문장으로 정의하고, 근거가 되는 예시 또는 테스트와 연결한다. 모두 “아니오”라면 지금은 파일명·함수명 같은 저장소 관례에 맡긴다.

좋은 항목의 모양

용어: 정리
의미: 기본 목록에서 제외하고 30일 동안 복구할 수 있게 보관한다.
반례: 영구 삭제는 정리가 아니라 삭제다.
검증: 30일 이내 복구 가능, 이후에는 보존 정책에 따른다.
